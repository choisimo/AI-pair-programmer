## TASK-037: 테스트 전략 및 커버리지 목표 정의
- **카테고리**: Testing & Quality
- **우선순위**: P0
- **예상 소요시간**: 2일
- **의존성**: -
- **담당 모드**: architect

### 설명
프로젝트 전반의 테스트 전략(Unit, Integration, E2E, Visual)과 커버리지 목표를 수립한다. 우선순위 테스트 시나리오와 위험 기반 접근을 문서화한다.

### 체크리스트
- [ ] 테스트 피라미드 정의 및 각 계층별 목표 작성
- [ ] 커버리지 KPI(라인, 브랜치, 기능) 설정
- [ ] 회귀 테스트 주기 및 자동화 정책 수립
- [ ] 문서 리뷰 및 PRD 업데이트

### 수락 기준
- 전략 문서가 `docs/prd/services/testing-quality.md`에 반영
- 커버리지 목표가 CI 리포트와 연동될 수 있도록 정의

### 기술 노트
- Phase 1 최소 기준: 라인 70%, 브랜치 60%
- 고위험 영역(Core AI, Parser)에 대한 집중 테스트 전략 포함

## TASK-038: 테스트 런너 구성 및 CI 통합
- **카테고리**: Testing & Quality
- **우선순위**: P0
- **예상 소요시간**: 3일
- **의존성**: TASK-037, TASK-030
- **담당 모드**: devops

### 설명
Jest/Vitest 기반 테스트 런너 환경을 구성하고 CI 파이프라인에 통합한다. 병렬 실행, 캐싱, 스냅샷 관리 전략을 포함한다.

### 체크리스트
- [ ] 테스트 설정 파일(vitest.config.ts 등) 구성
- [ ] CI 워크플로에 테스트 단계 추가 및 캐시 전략 적용
- [ ] 실패 시 아티팩트(로그, 스냅샷) 업로드 처리
- [ ] 테스트율 배지/리포트 게시

### 수락 기준
- CI에서 테스트가 병렬로 실행되고 10분 내 완료
- 실패 시 Slack/이메일 알림 발송 확인

### 기술 노트
- Watch 모드 및 Coverage 모드 설정 분리
- 테스트 격리를 위해 환경 변수 모킹 전략 문서화

## TASK-039: 회귀 테스트 스위트 1차 작성
- **카테고리**: Testing & Quality
- **우선순위**: P0
- **예상 소요시간**: 4일
- **의존성**: TASK-038
- **담당 모드**: jest-test-engineer

### 설명
핵심 기능(Core AI Suggest, Parser, Notifications)에 대한 회귀 테스트 스위트를 작성한다. 스냅샷 테스트와 행동 기반 테스트를 포함한다.

### 체크리스트
- [ ] 핵심 사용자 시나리오 테스트 추가 (5개 이상)
- [ ] 모킹/스토빙 전략 설정 및 재사용 가능하게 구성
- [ ] 스냅샷 검증(제안 결과 등) 작성
- [ ] 테스트 실행 문서 및 Troubleshooting 가이드 작성

### 수락 기준
- 회귀 테스트가 CI에서 안정적으로 통과
- 실패 시 원인 분석에 필요한 로그/디버깅 정보 포함

### 기술 노트
- API 요청은 MSW(Mock Service Worker) 활용
- 스냅샷은 안정성을 위해 시드 데이터 고정

## TASK-040: 품질 게이트 자동화
- **카테고리**: Testing & Quality
- **우선순위**: P0
- **예상 소요시간**: 2일
- **의존성**: TASK-038, TASK-039
- **담당 모드**: devops

### 설명
테스트 실패, 커버리지 미달, 린트 오류 발생 시 머지 차단 및 알림을 수행하는 품질 게이트를 구축한다.

### 체크리스트
- [ ] 커버리지 임계치 설정 및 체크 스크립트 작성
- [ ] 머지 차단 규칙(GitHub Branch Protection 등) 적용
- [ ] 품질 리포트 대시보드 구성
- [ ] 예외 처리(긴급 핫픽스) 프로세스 문서화

### 수락 기준
- 품질 게이트 위반 시 머지가 차단되고 알림이 전송
- 대시보드에 품질 지표(커버리지, 테스트 성공률) 노출

### 기술 노트
- Codecov/SonarQube 연동 고려
- 린트/타입 체크 결과도 게이트에 포함
