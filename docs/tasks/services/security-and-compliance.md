## TASK-025: 민감 데이터 레드액션 정책 수립
- **카테고리**: Security & Compliance
- **우선순위**: P0
- **예상 소요시간**: 2일
- **의존성**: TASK-021
- **담당 모드**: security-review

### 설명
Prompt/로그/텔레메트리 경로에 대한 민감 데이터(Pll, 토큰 등) 레드액션 정책을 정의한다. 정규식 패턴과 허용/차단 목록을 포함한다.

### 체크리스트
- [ ] 민감 데이터 분류 및 우선순위 지정
- [ ] 레드액션 패턴(Regex, Hashing) 작성
- [ ] 허용 목록(Whitelist) 및 예외 처리 규정 정의
- [ ] 검토 및 승인

### 수락 기준
- 정책 문서가 `docs/prd/services/security-and-compliance.md`에 반영
- PII 레드액션 규칙이 Telemetry/Prompt Guardrail에 공유됨

### 기술 노트
- Regex는 Phase 1에서 이메일, 토큰, Secret Key 집중
- 로그 마스킹 수준(완전 마스킹 vs 부분 마스킹) 명시

## TASK-026: PII 스캐닝 미들웨어 구현
- **카테고리**: Security & Compliance
- **우선순위**: P0
- **예상 소요시간**: 3일
- **의존성**: TASK-025, TASK-022
- **담당 모드**: code

### 설명
모델 호출 전/후, 로깅 시 PII 스캐닝을 수행하는 미들웨어를 구현한다. 발견 시 차단 또는 마스킹을 적용한다.

### 체크리스트
- [ ] 요청/응답 PII 스캐닝 모듈 구현
- [ ] 레드액션 정책(TASK-025) 적용
- [ ] 위반 시 알림 및 로깅 처리
- [ ] 단위 테스트 및 퍼포먼스 검증

### 수락 기준
- PII 검출률이 정의된 샘플 세트에서 95% 이상
- 위반 이벤트가 Telemetry에 기록되고 차단 로직 동작

### 기술 노트
- 텍스트 외에 Code Block/JSON 등 구조화된 데이터도 검사
- 추후 ML 기반 감지기 대체를 고려하여 인터페이스 추상화

## TASK-027: 감사 로그 스키마 설계
- **카테고리**: Security & Compliance
- **우선순위**: P0
- **예상 소요시간**: 2일
- **의존성**: TASK-025
- **담당 모드**: architect

### 설명
사용자 행동 및 시스템 이벤트에 대한 감사 로그 스키마를 설계하고 데이터 보존 정책을 정의한다.

### 체크리스트
- [ ] 감사 이벤트 카테고리 정의 (auth, config, suggestion 등)
- [ ] 필수 필드(주체, 대상, 액션, 결과, 타임스탬프) 지정
- [ ] 보존 정책 및 접근 제어 규칙 문서화
- [ ] 리뷰 및 승인을 거쳐 PRD 업데이트

### 수락 기준
- 감사 로그 스키마가 `docs/prd/services/security-and-compliance.md`에 반영
- 보존 정책(예: 180일)과 접근 권한(Role) 명시

### 기술 노트
- Telemetry와 분리된 보안 저장소 고려
- JSON Lines 형식으로 저장, Rotation 정책 명시

## TASK-028: 보안 감사 체크리스트 자동화
- **카테고리**: Security & Compliance
- **우선순위**: P0
- **예상 소요시간**: 3일
- **의존성**: TASK-026, TASK-027
- **담당 모드**: devops

### 설명
주요 보안 체크리스트(비밀키 만료, 레드액션 실패, 감사 로그 누락)를 자동 점검하는 스크립트와 대시보드를 구성한다.

### 체크리스트
- [ ] 보안 체크 항목 정의 및 스크립트화
- [ ] CI/CD 파이프라인에 보안 검증 단계 추가
- [ ] 대시보드/알림 시스템과 연동 (Slack, Email)
- [ ] 실패 시 대응 프로세스 문서화

### 수락 기준
- 자동화 스크립트가 주기적으로 실행되고 결과 기록
- 보안 위반 발생 시 알림이 5분 내 발송됨

### 기술 노트
- `Deployment & Ops` TASK-030과 파이프라인 통합
- KPI: 보안 체크 실패 건수, 해결 평균 시간(MTTR)
