## TASK-029: IaC 환경 기초 템플릿
- **카테고리**: Deployment & Ops
- **우선순위**: P0
- **예상 소요시간**: 3일
- **의존성**: -
- **담당 모드**: devops

### 설명
개발/프리뷰/프로덕션 환경을 위한 기본 IaC 템플릿(Terraform 또는 equivalent)을 작성하고 네트워크, 컴퓨팅, 시크릿 저장소 리소스를 정의한다.

### 체크리스트
- [ ] 환경별 변수 파일 분리
- [ ] VPC/서브넷/보안 그룹 기본 정의
- [ ] 애플리케이션 런타임(컨테이너/서버리스) 리소스 생성 스크립트 작성
- [ ] 초기 릴리즈 노트와 검증 로그 첨부

### 수락 기준
- IaC 코드가 리포지토리에 추가되고 `terraform plan` (또는 동등 명령) 검증 완료
- 환경 프로비저닝 가이드가 문서화됨

### 기술 노트
- 초기에는 Terraform Cloud/Remote Backend 없이 로컬 상태, 추후 백엔드 전환 고려
- 시크릿은 외부 Secret Manager와 연동 예정

## TASK-030: CI/CD 파이프라인 구성
- **카테고리**: Deployment & Ops
- **우선순위**: P0
- **예상 소요시간**: 4일
- **의존성**: TASK-029, TASK-024
- **담당 모드**: devops

### 설명
빌드, 테스트, 품질 게이트, 배포 단계가 포함된 CI/CD 파이프라인을 구축한다. 브랜치 전략 및 배포 트리거를 정의한다.

### 체크리스트
- [ ] CI 워크플로(빌드/테스트/린트) 구성
- [ ] 배포 파이프라인(Preview/Prod) 스크립트 작성
- [ ] 배포 승인 단계 및 롤백 전략 문서화
- [ ] 파이프라인 상태 모니터링 대시보드 연동

### 수락 기준
- PR 생성 시 CI가 자동 실행되고 결과 공유
- main 브랜치 머지 시 Preview 배포 자동화

### 기술 노트
- GitHub Actions 또는 GitLab CI 기준으로 설계, YAML 템플릿화
- 배포 아티팩트는 Docker 이미지 또는 Static 빌드 산출물

## TASK-031: 카나리 릴리즈 전략 구현
- **카테고리**: Deployment & Ops
- **우선순위**: P0
- **예상 소요시간**: 3일
- **의존성**: TASK-030
- **담당 모드**: devops

### 설명
카나리 릴리즈를 위한 트래픽 분할, 모니터링, 롤백 절차를 구현한다. Feature Flag와 연동하여 단계적 출시를 지원한다.

### 체크리스트
- [ ] 카나리 배포 스크립트/워크플로 작성
- [ ] 트래픽 루팅(LB 혹은 Proxy) 설정 문서화
- [ ] 헬스체크 및 자동 롤백 조건 정의
- [ ] Canary 성과 리포트 템플릿 마련

### 수락 기준
- 카나리 배포 시 10%-30%-100% 전환 플로우가 동작
- 실패 시 자동 롤백 및 알림 발송 확인

### 기술 노트
- Metrics/Logs는 `Telemetry & Observability` TASK-035와 연동
- Feature Flag 기반 Soft Canary 고려

## TASK-032: 런타임 헬스 프로브 세트
- **카테고리**: Deployment & Ops
- **우선순위**: P0
- **예상 소요시간**: 2일
- **의존성**: TASK-029
- **담당 모드**: devops

### 설명
애플리케이션 헬스 체크(라이브니스, 레디니스, 메트릭 엔드포인트)를 정의하고 배포 환경에서 사용 가능한 형태로 제공한다.

### 체크리스트
- [ ] /health/live, /health/ready 엔드포인트 구현
- [ ] 메트릭 익스포저(`/metrics` 또는 equivalent) 설정
- [ ] 헬스체크 실패시 알림 흐름 구성
- [ ] 문서 및 예제 구성

### 수락 기준
- 헬스 프로브가 Kubernetes/컨테이너 오케스트레이션과 연동
- 장애 시 알람이 2분 내 발송됨

### 기술 노트
- 메트릭 수집은 Prometheus/OpenTelemetry Exporter 기반
- 헬스체크는 외부 의존 서비스(LLM API) 상태도 포함
