## TASK-201: i18n 키 전략 정의
- **카테고리**: Internationalization
- **우선순위**: P2
- **예상 소요시간**: 2일
- **의존성**: TASK-041, TASK-021
- **담당 모드**: architect

### 설명
i18n 키 네이밍 규칙, 네임스페이스 구조, 번역 리소스 파일 전략을 정의한다. 문자열 추출 및 동기화를 위한 워크플로를 설계한다.

### 체크리스트
- [ ] 네임스페이스 구조(예: `common`, `core`, `notifications`) 결정
- [ ] 키 네이밍 규칙 및 가이드 작성
- [ ] 문자열 추출 자동화 도구 검토 및 선택
- [ ] 문서 리뷰 및 PRD 업데이트

### 수락 기준
- i18n 전략 문서가 `docs/prd/services/internationalization.md`에 반영
- 문자열 관리 워크플로(추출 → 번역 → 배포)가 정의

### 기술 노트
- 키는 kebab-case 혹은 dot 표기법 중 선택하여 일관성 유지
- Phase 1에서는 EN/KO, Phase 2에서 기타 언어 확장

## TASK-202: 번역 리소스 로더 구현
- **카테고리**: Internationalization
- **우선순위**: P2
- **예상 소요시간**: 3일
- **의존성**: TASK-201, TASK-022
- **담당 모드**: code

### 설명
번역 리소스를 로드하고 런타임에서 언어 전환을 처리하는 i18n 모듈을 구현한다. Lazy Loading과 캐싱 전략을 포함한다.

### 체크리스트
- [ ] i18n 라이브러리 선택(i18next 등) 및 초기 설정
- [ ] 리소스 로더 및 캐싱 로직 구현
- [ ] 언어 전환 API/훅 제공 (`useLocale` 등)
- [ ] 단위 테스트 및 샘플 컴포넌트 작성

### 수락 기준
- 언어 전환이 페이지 리로드 없이 수행
- 리소스 로드 실패 시 폴백 언어가 적용

### 기술 노트
- 번역 파일은 JSON 기반, Phase 2에서 remote fetch 고려
- Feature Flag로 다국어 활성화 제어 가능해야 함

## TASK-203: 다국어 스위칭 UX
- **카테고리**: Internationalization
- **우선순위**: P2
- **예상 소요시간**: 2일
- **의존성**: TASK-201, TASK-050
- **담당 모드**: code

### 설명
사용자가 언어를 전환할 수 있는 UI 컴포넌트를 구현하고, 현재 언어 상태를 레이아웃 내에 반영한다.

### 체크리스트
- [ ] 언어 선택 드롭다운/토글 컴포넌트 구현
- [ ] 선택한 언어가 `Routing & Application Shell`에 반영되도록 연동
- [ ] 언어 변경 시 알림/토스트 메시지 적용
- [ ] A11y 및 키보드 내비게이션 테스트

### 수락 기준
- 언어 전환 UI가 레이아웃에 통합되고, 선택 상태 유지
- Telemetry에 언어 전환 이벤트 기록

### 기술 노트
- 브라우저 언어 감지(Phase 1 Optional) 및 저장(LocalStorage) 전략 포함
- 다국어 카피 가이드는 `Content Sections` TASK-112와 연결

## TASK-204: 번역 품질 검증 파이프라인
- **카테고리**: Internationalization
- **우선순위**: P2
- **예상 소요시간**: 2일
- **의존성**: TASK-202
- **담당 모드**: documentation-writer

### 설명
번역 품질 검증을 위한 체크리스트와 자동화 스크립트를 마련하고, 언어별 리뷰 프로세스를 정의한다.

### 체크리스트
- [ ] 번역 QA 체크리스트 작성
- [ ] 자동화 스크립트(플레이스홀더 검사 등) 구성
- [ ] 리뷰어 할당 프로세스 문서화
- [ ] 피드백 반영 워크플로 정의

### 수락 기준
- 번역 검증 프로세스가 위키/문서에 게시
- 자동화 스크립트가 CI에서 실행되고 결과 보고

### 기술 노트
- ICU/플레이스홀더 누락 검사를 중점으로 삼을 것
- Phase 2에서 번역 메모리 도구 연동 고려
